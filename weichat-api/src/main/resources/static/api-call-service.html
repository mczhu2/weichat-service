5. 二次扫码授权登陆接口

接口调用流程说明：
1. 先调用 1. 初始化接口获取 uuid。
2. 再调用 3. 获取登录二维码接口，展示二维码让用户扫码。
3. 用户扫码后，调用 4. 录入登陆授权码接口提交授权码。
4. 只有第一次登录时，4. 录入登陆授权码成功后，才有可能要求二次扫码授权。
5. 如果返回结果提示需要二次授权，再调用本接口生成/获取二次验证二维码。
6. 用户完成二次扫码授权后，再调用 6. 检查用户是否登录成功接口确认 loginType 和 longLinkState。
注意：不是每次登录都需要调用本接口；老账号或已授权账号通常可跳过。

响应结果

仅第一次登录且第4步录入授权码成功后提示需要二次授权时，再调用本接口
判断是否需要调用：
- 第4步成功且返回二次验证/二次授权提示：调用本接口。
- 第4步成功后账号已登录：跳过本接口，直接检查登录状态。
- 第4步失败：先处理授权码错误，不调用本接口。

7. 自动登录（可选）

调用说明：
初始化接口传递过 vid 时，可用本接口根据 uuid 自动登录。
如果初始化时没有传 vid，自动登录通常失败。账号首次扫码登录成功后，后续可复用 vid + uuid 做自动登录。

响应结果

可选接口：有历史 vid 并已初始化拿到 uuid 后调用

接口路径

请求路径：
POST /wx/api/v1/init/automaticLogin

8. 退出登录（可选）

调用说明：
按 uuid 退出当前企业微信实例。退出后该 uuid 对应实例不再保持登录态；如需继续使用，需要重新登录或重新初始化。

响应结果

可选接口：确认需要退出当前 uuid 登录态时调用

接口路径

请求路径：
POST /wx/api/v1/init/loginOut
